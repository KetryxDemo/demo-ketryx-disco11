# NeuroCue Clinician Programmer

Clinician-facing programming application for the NeuroCue spinal cord stimulation
system. The programmer establishes a telemetry session with an implanted pulse
generator and lets a clinician review and adjust stimulation therapy.

This repository is traced by Ketryx:

- `specs/*.md` are software item specs, each fulfilling one or more requirements
  in Jira (`NC-*`).
- `features/*.feature` are Cucumber scenarios. Each scenario becomes a Ketryx
  Test Case and reports executions through the Ketryx GitHub Action.

Demo environment. Not a real medical device.
